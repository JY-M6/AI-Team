# 钱迹部署文档

## 当前状态

项目尚未进入开发和部署阶段。本文件先记录部署规划，后续由 `@运维部署工程师` 在技术栈确认后补齐实际命令和配置。

## 可能部署组成

| 部分 | 说明 |
|---|---|
| 小程序端 | 微信小程序或跨端小程序构建产物 |
| 后端服务 | 提供账单、统计、AI、理财数据接口 |
| 数据库 | 存储用户、账单、分类、预算、反馈等数据 |
| AI 服务配置 | 通过环境变量配置 API Key 和模型信息 |
| 理财数据源配置 | 配置财经 API 或手动维护数据源 |

## 环境变量原则

- 不把真实 API Key、token、密码写进代码或 README。
- 本地开发、测试部署、生产部署必须分环境配置。
- AI API Key 和理财数据 API Key 必须走环境变量或本地私有配置。

## 部署前必须确认

1. 技术栈和构建方式。
2. 后端端口。
3. 数据库类型和连接方式。
4. AI API 供应商和配置项。
5. 理财数据来源。
6. 日志路径。
7. 健康检查方式。
8. 回滚方案。
