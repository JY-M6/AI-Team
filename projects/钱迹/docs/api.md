# 钱迹接口文档

## 当前状态

本项目仍处于产品梳理和技术选型阶段，接口尚未进入正式设计。

## 第一版接口范围

后续进入后端设计时，至少需要覆盖以下接口：

| 模块 | 接口方向 | 说明 |
|---|---|---|
| 用户 | 登录、获取当前用户 | 小程序身份识别和用户基础信息 |
| 账单 | 新增、编辑、删除、查询账单 | 支持收入、支出、日期、分类、备注 |
| 分类 | 查询分类、管理自定义分类 | 第一版可先使用默认分类 |
| 日历 | 查询某月每日支出汇总 | 支持日历视图展示 |
| 统计 | 查询月度收支、分类占比、趋势 | 支持统计页展示 |
| 预算 | 设置预算、查询预算执行情况 | 支持月预算和分类预算 |
| AI | 发起消费分析、理财辅助问答 | 必须带用户授权和风险提示 |
| 理财 | 查询理财产品基础信息 | 第一版数据来源待定 |
| 反馈 | 提交试用反馈 | 支持冷启动反馈收集 |

## 接口设计原则

- 不直接暴露数据库实体给前端。
- 所有用户数据必须按当前用户隔离。
- AI 接口不得读取未授权账单数据。
- 理财相关接口不得执行购买、赎回或资金转移。
- 错误信息要可理解，但不能泄露敏感实现细节。
