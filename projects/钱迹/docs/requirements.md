# 钱迹需求文档

## 目标

做一个智能记账小程序，让用户可以轻松记录收支、查看每日和每月消费情况，并获得 AI 生成的消费建议和理财辅助建议。

## 目标用户

- 有日常记账需求的学生和年轻上班族。
- 想控制月度支出的个人用户。
- 想了解自己消费结构，但不想手动做复杂表格的用户。
- 对理财感兴趣，但需要风险提示和基础解释的用户。

## MVP 范围

第一版重点完成：

1. 手动记账。
2. 日历查看每日支出。
3. 每日消费明细。
4. 月度统计和消费结构。
5. AI 消费建议。
6. 简版理财产品信息。
7. AI 理财辅助建议。
8. 冷启动反馈收集。

## 验收标准

| 功能 | 验收标准 |
|---|---|
| 记一笔 | 用户可以新增收入或支出记录 |
| 日历账单 | 用户可以在日历中看到每天支出总额 |
| 每日明细 | 用户点击日期后能看到当天所有记录 |
| 月度统计 | 系统能展示本月收入、支出、结余和分类占比 |
| AI 消费建议 | AI 能基于用户账单给出消费分析和建议 |
| 理财板块 | 系统能展示理财产品的基础信息和风险等级 |
| AI 理财辅助 | AI 建议必须包含风险提示，不承诺收益 |
| 冷启动反馈 | 能收集第一批试用用户对记账流程、页面体验和 AI 建议的反馈 |

## 当前风险

- 理财产品信息如果接真实数据源，需要确认 API、频率、合规和成本。
- AI 能看到用户消费数据，必须设计清晰的授权边界。
- 主题切换功能后期再做，第一版只保留设计扩展空间。
- 增长运营不能夸大理财收益、AI 准确性或未上线功能。
