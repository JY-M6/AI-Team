# 钱迹数据库文档

## 当前状态

数据库尚未进入正式设计。本文件先记录第一版可能需要的数据对象，后续由 `@数据库工程师` 在业务规则确认后补齐表结构。

## 核心数据对象

| 对象 | 说明 |
|---|---|
| 用户 | 小程序用户身份、昵称、头像等基础信息 |
| 账单记录 | 收入、支出、金额、分类、日期、备注 |
| 消费分类 | 默认分类和用户自定义分类 |
| 预算 | 月预算、分类预算、预算提醒设置 |
| AI 分析记录 | 用户发起的 AI 分析请求和结果摘要 |
| 理财产品 | 产品名称、类型、风险等级、收益信息来源 |
| 用户反馈 | 冷启动试用反馈和评分 |

## 设计原则

- 所有用户账单必须关联用户身份。
- 金额字段必须使用适合精确计算的类型，避免浮点误差。
- 账单查询要优先支持按月份、日期、分类筛选。
- AI 分析记录不得保存不必要的隐私明细。
- 理财产品信息需要记录数据来源和更新时间。
- 删除用户数据时要考虑软删除或可恢复策略。

## 待确认
