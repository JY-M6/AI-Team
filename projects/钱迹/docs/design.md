# 钱迹设计文档

## 默认风格

第一版默认使用年轻潮流型。

## 视觉方向

| 维度 | 方案 |
|---|---|
| 主色 | 蓝紫、珊瑚橙、荧光绿择一为主，其他作为点缀 |
| 背景 | 明亮、干净、有轻微层次 |
| 图标 | 简洁、有一点趣味感 |
| 卡片 | 信息密度适中，突出金额、趋势和 AI 建议 |
| 图表 | 颜色鲜明，但不要影响阅读 |
| AI 助手 | 可以更有个性，像一个懂消费习惯的财务搭子 |

## 主题规划

后期可以支持主题切换，但第一版不做完整主题系统。

候选主题：

1. 年轻潮流型。
2. 清新治愈型。
3. 高级金融型。
4. 极简数据仪表盘型。
5. 温暖生活账本型。

## 核心页面体验

- 首页要让用户一眼看到本月花了多少、还剩多少预算。
- 记一笔必须快，金额和分类优先。
- 日历要直观看到哪几天花得多。
- 统计页要突出消费结构，而不是堆太多图。
- AI 助手要能主动总结，也能回答用户提问。
