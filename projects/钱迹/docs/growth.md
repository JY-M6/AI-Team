# 钱迹增长运营文档

## 产品卖点

- 用日历方式看清每天花了多少钱。
- 用月度统计看清钱花在哪些分类。
- 用 AI 帮用户理解消费习惯和节省空间。
- 用理财信息辅助用户理解常见产品，但不替用户做投资决策。

## 目标用户

- 大学生。
- 刚工作的年轻人。
- 想控制月度支出的个人用户。
- 想看懂自己消费结构，但不想做复杂表格的用户。

## 宣传渠道

| 渠道 | 方向 |
|---|---|
| 抖音 | 短视频演示、消费复盘选题、记账前后对比 |
| 朋友圈 | 招募第一批试用用户，强调真实反馈 |
| 小红书 | 年轻人记账、月底复盘、消费控制经验 |
| 视频号 | 产品演示、AI 消费建议展示 |
| 校园社群 | 招募种子用户，验证大学生日常记账场景 |

## 内容选题

1. 大学生一个月到底钱花哪了。
2. 月底发现奶茶和外卖花了多少钱是什么体验。
3. 用 AI 帮你总结本月消费习惯。
4. 不做复杂表格，也能看懂自己的消费结构。
5. 记账不是省钱焦虑，而是看清自己的生活节奏。

## 朋友圈文案

```text
我在做一个叫「钱迹」的智能记账小程序。

它可以记录日常收支，用日历看每天花了多少钱，还能让 AI 帮你总结本月消费习惯。

现在想找 20 个朋友做第一批试用，帮我看看：
1. 记账流程顺不顺手
2. 页面好不好看
3. AI 建议有没有帮助
4. 哪些功能最想要

愿意试用的话可以私信我，我会认真收集反馈继续迭代。
```

## 抖音短视频脚本

```text
标题：大学生一个月的钱到底花哪了？

开头 3 秒：
你有没有月底突然发现钱没了，但完全不知道花在哪？

中段：
展示钱迹的日历账单、月度分类统计和 AI 消费总结。

结尾：
我正在做这个 AI 记账小程序，想找第一批试用用户。如果你也想知道自己的钱花哪了，可以来帮我提提意见。
```

## 种子用户获取

第一批建议目标：20 到 50 人。

来源建议：

- 身边同学和朋友。
- 校园社群。
- 朋友圈。
- 小红书评论区。
- 抖音私信。

筛选标准：

- 愿意连续试用 7 天。
- 愿意提交真实反馈。
- 能接受产品早期不完善。
- 不要求导入真实支付账单，第一版先手动记录或用模拟数据。

## 反馈收集方式

建议反馈表包含：

| 问题 | 类型 |
|---|---|
| 你是否愿意继续使用？ | 单选 |
| 记一笔是否顺手？ | 评分 |
| 日历账单是否看得懂？ | 评分 |
| 月度统计是否有帮助？ | 评分 |
| AI 消费建议是否有帮助？ | 评分 |
| 你最想增加什么功能？ | 文本 |
| 你最不喜欢哪里？ | 文本 |

## 数据指标

| 指标 | 第一版关注点 |
|---|---|
| 曝光 | 内容是否有人看到 |
| 点击 | 文案和选题是否能吸引用户 |
| 试用 | 是否有人愿意进入小程序 |
| 首次记账 | 用户是否能完成第一笔记录 |
| 7 日反馈 | 用户是否愿意持续试用并反馈 |

## 风险与注意事项

- 不承诺理财收益。
- 不把 AI 建议说成确定结论。
- 不展示真实用户隐私账单。
- 不编造用户数量和使用数据。
- 不夸大未完成的功能。

## 交接给产品经理

增长运营收集到反馈后，需要交接：

- 用户最常提到的痛点。
- 用户最期待的功能。
- 用户最难理解的页面或流程。
- 哪些宣传卖点真的有效。
- 下一轮 MVP 是否需要调整。
