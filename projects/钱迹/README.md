# 💸 钱迹

**让每一笔钱，都留下清楚的轨迹**

`状态：规划中` · `平台：小程序` · `AI：消费建议 + 理财辅助` · `风格：年轻潮流型`

---

## ✨ 项目简介

`钱迹` 是一个面向个人用户的智能记账小程序。

它不只是记录“花了多少钱”，而是帮助用户看清：

- 🧾 每一天的钱花在哪里。
- 📅 哪些日期支出明显偏高。
- 📊 每个月的消费结构是什么样。
- 🤖 AI 能从账单里发现哪些消费习惯。
- 🪙 当前主流理财产品大概是什么情况。
- 💡 用户应该如何更理性地控制支出和规划结余。

一句话：**钱迹 = 记账 + 日历 + 统计 + AI 财务助手 + 理财信息辅助。**

---

## 🎨 默认设计方向

第一版默认采用 **年轻潮流型**。

| 维度 | 方案 |
|---|---|
| 视觉关键词 | 年轻、有趣、个性、活泼、智能助手 |
| 推荐主色 | 蓝紫、珊瑚橙、荧光绿等高识别度配色 |
| 页面气质 | 比传统记账软件更轻松，更像一个懂你的 AI 财务搭子 |
| 交互重点 | 快速记账、日历查看、图表洞察、AI 对话 |
| 后续规划 | 增加主题切换功能，允许用户切换不同视觉风格 |

> 第一版只实现默认主题。主题切换先作为后续规划，避免一开始把样式系统做复杂。

## ⏸️ 第一版暂不做

| 功能 | 暂缓原因 |
|---|---|
| 支付账单自动导入 | 涉及第三方数据授权和解析，第一版先手动记账 |
| OCR 识别小票 | 增加 AI 识别链路复杂度，后续再做 |
| 多账本 | 会增加账本权限和统计维度复杂度 |
| 家庭共享账本 | 涉及多人协作和权限边界 |
| 自动购买理财产品 | 风险高，不符合 AI 辅助建议边界 |

## 📣 增长运营方向

第一版上线后，不只验证功能是否能用，还要验证是否有人愿意点进来、愿意记第一笔账、愿意反馈真实体验。

| 渠道 | 初始方向 |
|---|---|
| 抖音 | 大学生 / 年轻人月底钱花哪了、AI 自动分析消费习惯 |
| 朋友圈 | 招募第一批试用用户，收集记账流程和 UI 反馈 |
| 小红书 | 年轻人记账、消费复盘、月度开销管理 |
| 视频号 | 产品演示、记账前后对比、AI 消费建议展示 |
| 校园社群 | 招募种子用户，验证真实记账场景 |

增长运营必须遵守：不承诺收益、不夸大 AI 建议准确性、不收集无关隐私数据。

详细方案见 [增长运营文档](docs/growth.md)。

## ⚠️ AI 与理财边界

AI 可以帮助用户理解消费习惯和理财产品信息，但不能替用户做投资决策。

AI 不允许：

- 承诺收益。
- 自动购买或赎回理财产品。
- 把建议表达成确定性结论。
- 读取未授权的隐私数据。

理财相关回答必须包含：

```text
以下内容仅供参考，不构成投资建议。理财产品存在风险，请结合自身情况谨慎决策。
```
