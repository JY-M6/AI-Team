# 💸 钱迹

**让每一笔钱，都留下清楚的轨迹**

`状态：P0 核心链路联调中` · `当前平台：Vue 网页端` · `后续平台：微信小程序` · `AI：消费建议 + 理财辅助`

---

## ✨ 项目简介

`钱迹` 是一个面向个人用户的智能记账小程序。

它不只是记录“花了多少钱”，而是帮助用户看清：

- 🧾 每一天的钱花在哪里。
- 📅 哪些日期支出明显偏高。
- 📊 每个月的消费结构是什么样。
- 🤖 AI 能从账单里发现哪些消费习惯。
- 🪙 当前主流理财产品大概是什么情况。
- 💡 用户应该如何更理性地控制支出和规划结余。

一句话：**钱迹 = 记账 + 日历 + 统计 + AI 财务助手 + 理财信息辅助。**

---

## 🎨 默认设计方向

第一版默认采用 **年轻潮流型**。

| 维度 | 方案 |
|---|---|
| 视觉关键词 | 年轻、有趣、个性、活泼、智能助手 |
| 推荐主色 | 蓝紫、珊瑚橙、荧光绿等高识别度配色 |
| 页面气质 | 比传统记账软件更轻松，更像一个懂你的 AI 财务搭子 |
| 交互重点 | 快速记账、日历查看、图表洞察、AI 对话 |
| 后续规划 | 增加主题切换功能，允许用户切换不同视觉风格 |

> 第一版只实现默认主题。主题切换先作为后续规划，避免一开始把样式系统做复杂。

## ⏸️ 第一版暂不做

| 功能 | 暂缓原因 |
|---|---|
| 支付账单自动导入 | 涉及第三方数据授权和解析，第一版先手动记账 |
| OCR 识别小票 | 增加 AI 识别链路复杂度，后续再做 |
| 多账本 | 会增加账本权限和统计维度复杂度 |
| 家庭共享账本 | 涉及多人协作和权限边界 |
| 自动购买理财产品 | 风险高，不符合 AI 辅助建议边界 |

## 📱 页面端预览

当前已先完成页面端响应式原型，用于确认整体视觉、信息结构和手机端体验。

| 项 | 说明 |
|---|---|
| 工程入口 | [frontend/](frontend/) |
| 形式 | Vue 3 + Vite 单页应用 |
| 重点 | 手机优先，同时适配电脑宽屏 |
| 覆盖页面 | 登录、总览、记一笔、日历、每日明细、统计、理财、我的、设置子页 |

本地运行：

```bash
cd frontend
npm install
npm run dev
```

> 当前版本用于验证 P0 核心链路。账户与分类已接后端接口；行情、AI 回复、标签及部分设置仍为原型，不代表线上能力已经完成。

后端工程位于 [backend/](backend/)。当前已完成认证、账本、账户、收支与转账、分类、月历统计和预算等 P0 核心接口；核心页面正在联调，AI SSE 仍待完成。

浏览器 AI 模型在首次使用时按需下载并缓存，不随首屏加载。量化权重体积较大，移动端应在用户确认后再开始下载。

最新页面方向：

- AI 不再作为孤立模块，而是嵌入总览、记账、日历、每日明细、统计和理财各模块中自动分析。
- 日历点击某一天后，会展示当天具体消费记录和当天 AI 分析。
- 记账时间精确到分钟，默认使用记账时的当前时间。
- 理财从泛产品类型升级为“分类 → 产品列表 → 产品详情”，例如 ETF 基金下展示半导体 ETF、沪深 300 ETF，并在产品详情里展示走势和 AI 分析。
- 完整功能清单已按核心基础、统计分析、进阶实用、体验配套、后台管理、变现增值分层整理。

## ⚠️ AI 与理财边界

AI 可以帮助用户理解消费习惯和理财产品信息，但不能替用户做投资决策。

AI 不允许：

- 承诺收益。
- 自动购买或赎回理财产品。
- 把建议表达成确定性结论。
- 读取未授权的隐私数据。

理财相关回答必须包含：

```text
以下内容仅供参考，不构成投资建议。理财产品存在风险，请结合自身情况谨慎决策。
```
